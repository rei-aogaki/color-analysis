# GitHub Pagesへの初回公開

公開日：2026-10-19。ユーザーからの公開指示に基づき実施。

公開URL：[color-analysis](https://rei-aogaki.github.io/color-analysis/)

## 設定と結果

- Pagesの配信方式をGitHub Actionsに設定し、リポジトリ変数 `PAGES_ENABLED=true` を有効化した。
- `github-pages` 環境はmainブランチからのデプロイだけを許可する。ワークフロー側のmain限定条件も維持する。
- GitHubの非公開脆弱性報告を有効化し、SECURITY.mdへ案内を記載した。
- [初回公開のActions](https://github.com/rei-aogaki/color-analysis/actions/runs/39195193039)で履歴点検・検証・公開の全ジョブが成功した。アプリ公開時のコミットは `eea86ef`。
- Pages APIのHTTPS強制設定は有効。公開URLを証明書エラーを無視せずブラウザで開き、正常表示を確認した。
- mainへの必須チェックと強制push・削除禁止のブランチ保護は未設定。追加操作が自動承認レビューで「Pages公開とは別の永続設定」と判定され拒否されたため、ユーザーへ別途承認を依頼した。これは公開ジョブのmain限定とは別の設定。

## 公開サイトでの確認

Chromium 148.0.7778.96で、自作サンプルを使い次を確認した。

- HTTPSでのページ・JS/CSS・Workerの読み込み。
- 960,000画素のサンプル解析、色系統の強調と解除。
- CSVとJSONのダウンロード、JSONの全件数の一致。
- 幅390pxの表示でページ全体が横にはみ出さないこと。
- 固定の同一オリジン資産のGET以外に通信が発生しないこと。
- Cookie、localStorage、sessionStorage、IndexedDB、Cache Storageへユーザーデータを保存しないこと。
- ブラウザの実行エラーがないこと。

配信物はアプリ本体と必要な資産・通知の7ファイル。比較ページや文書、テスト、ユーザー画像を配信しない。公開サイトの確認でも実ユーザー画像は使用せず、公開用レポートにファイル名・メール・端末固有情報を記録しない。

公開サイトでの確認結果と合成サンプルのスクリーンショットは、Git除外済みの `.local/` に保存した。ユーザーによるスマホ実機確認とは別の検証であり、全端末・全ブラウザでの動作を保証するものではない。

更新・停止・差し戻しは[公開手順](publishing.md)、残る精度・性能・アクセシビリティの確認項目は[検証基準](verification.md)を参照する。
