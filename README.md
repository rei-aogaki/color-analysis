# color-analysis

画像に含まれる色を、カラーコード・ピクセル数・割合で確認するブラウザ用ツールです。

[ブラウザで使う](https://rei-aogaki.github.io/color-analysis/) — GitHub Pagesで公開している試作版です。PC・スマートフォンの両方に対応しています。

## 使い方

1. 端末内の画像を選択するか、画面にドラッグ＆ドロップします。
2. 「色の傾向」で、青系・赤系などの面積の割合を解析します。必要に応じて「完全一致」「似た色をまとめる」に切り替えられます。
3. 系統のボタンを押すと、画像内の該当箇所を確認できます。「元画像に戻す」で解除します。色系統モードは「その他」で省略せず全系統を表示します。
4. 必要に応じてCSVまたはJSONを準備し、「ダウンロード」で端末へ保存します。
5. 「クリア」で読み込んだ画像と結果を画面から取り除きます。

「色もどし」を押すと、画像がモノクロになり、なぞった所だけ元の色に戻せます。丸・くま・わんちゃんの形のブラシ、モノクロへの塗り戻し、元に戻す・やり直しに対応し、加工した画像をPNGで保存できます。解析結果の数値は変わりません。

解析後は「解析条件・再解析」で条件を変更できます。拡大・座標検査は「拡大・画素を詳しく調べる」、一覧・検索は「色の一覧・検索・並び替え」を開いてください。

「サンプルで試す」から、自分の画像を使わずに操作を確認できます。入力は静止PNG・JPEG・WebPに対応します。

## ローカルで起動する

Node.js 24.11以上が必要です。

```sh
npm ci
npm run build
npm run preview
```

表示されたローカルURLをブラウザで開いてください。開発・検証手順は[CONTRIBUTING.md](CONTRIBUTING.md)にあります。

デザイン比較は、表示されたURLの末尾に `design.html` を付けて開けます。A・Bの見た目を同じ画像・数値で切り替えて確認できます。[比較内容と検証](docs/design-comparison.md)を参照してください。

画像は端末内で処理し、アプリから外部へ送信・永続保存しない設計です。配信元のGitHub Pagesでは、GitHubがセキュリティ目的で訪問者のIPアドレスを記録します。

「完全一致」はブラウザから取得した画素値の一致を指します。元ファイル内の色値との完全一致を保証するものではありません。

入力上限は暫定で20MiB・1,600万画素・一辺8,192pxです。試作では完全一致の異なる色が100万を超える場合、部分結果を出さず中断します。スマホ実機ではユーザーによる動作確認済みです。端末・ブラウザのバージョン別の網羅的な検証は未完了です。[公開前点検](docs/release-review.md)を確認してください。

色の名前は本ツールで定めた分類ルールに基づく目安です。写真から受ける印象と面積比率は一致するとは限りません。[色分けのルールと検証](docs/color-families.md)を公開しています。0.2.0のCSV/JSONは出力形式v2で、系統名とルール版を保存できます。強調表示は数値や保存内容を変えません。

仕様と未決定事項は[ドキュメント一覧](docs/README.md)を参照してください。

GitHub Pagesへ公開済みです。[公開・更新手順](docs/publishing.md)と[公開時の確認結果](docs/deployment.md)を用意しています。リポジトリ履歴のメールについては[対応記録](docs/email-privacy.md)を参照してください。セキュリティ上の問題の報告は[SECURITY.md](SECURITY.md)を参照してください。
