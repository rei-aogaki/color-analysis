# A案への全機能統合

実施日：2026-10-19。状態：ローカル実装・自動検証済み、未公開。ユーザーが暫定採用したA（ギャラリー型）を通常の `index.html` に統合した。`design.html` は参考比較として残す。

## 変更と理由

画像の下に色帯、右に主要色と系統ごとの割合を置き、画像と統計の関係を見つけやすくした。元の完全一致、RGB区間分類、透明度設定、拡大・画素検査、検索・並び替え・ページ送り、CSV/JSON出力、キャンセル・クリアを維持する。

設定と検査の常時表示による情報量を減らすため、詳細パネルを折りたたむ。解析条件は最初に開き、解析完了後に閉じる。「解析条件・再解析」で条件を変更できる。キャンセルと進捗は設定の外に配置し、閉じていても操作できるようにした。

系統は多い順に並べ、0件は折りたたんで確認できるようにした。主要色と系統ボタンは小数点以下2桁の表示にし、厳密な件数と出力データは変えない。全対象画素の分類ルール、分母、画像の保持方針も変更しない。[画面仕様](design.md)

## 検証

- 型チェック・本番ビルド成功。数値・画像形式の単体テスト15件成功。
- 全機能画面のブラウザ検証14群成功。主要色と出力値の対応、0件系統の開閉、詳細パネルのキーボード操作に加え、下記の可変プレビュー枠も検証した。
- 1440・768・390・320px幅で、詳細パネルを開閉したときもページ全体の横はみ出しがないことを確認。全体表示、色の強調、画像差し替え、再解析、入力エラー、透明画像、検索・保存・キャンセルを確認。
- Chromiumのタッチエミュレーションで画像選択・解析・系統選択・画素検査・保存・画面回転を確認。
- 比較画面の6群の検証も成功。ブラウザのエラー、想定外の通信、Cookie・ブラウザストレージへのユーザーデータ保存は検出されなかった。

使用ブラウザ：Chromium 148.0.7778.96。実ユーザーの画像は検証資産に含めない。レポートと自作サンプルのスクリーンショットはGit除外済みの `.local/` に保存する。

## 追加改善：画像に合うプレビュー枠

縦写真では固定の横長枠の左右に余白が多いというユーザーの指摘に基づき、枠の幅と高さを元画像の比率・利用可能な列幅・画面高に合わせて計算するようにした。縦写真を大きく表示しつつ市松模様の余白を抑える。ズーム時は枠内をスクロールし、元画像の全画素集計と出力値は維持する。

PC幅1440pxとスマホ幅390pxで、縦長・横長・正方形・1画素の合成画像を検証した。枠と画像の寸法、縦横比、余白、横はみ出し、手動ズームと移動、全体表示への復帰、前後のJSONの一致を確認済み。実ユーザーの画像はテストに追加していない。
